### Increase the version and update the top `package.json`

The project uses [SemVer](https://semver.org), as required by npm.

- Determine the next version (such as <code>2.2.8</code>)
- Update the version in the top `package.json` file
- Use the new version, suffixed by `-pre`,
such as <code>2.2.8-pre</code>.
