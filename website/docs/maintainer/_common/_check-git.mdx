### Check Git

In the `xpack/doxygen2docusaurus-cli-ts` Git repository:

- Switch to the `development` branch
- Pull new changes
- If necessary, **rebase** the `master` branch onto the `development` branch
- If necessary, **rebase** the `website` branch onto the `development` branch

:::caution

Do not skip these steps; otherwise the previous content is released again.

:::

The `master` branch should remain unchanged since the previous release
and will be updated when the new release is published.
